# DailyLife – Personal Life Manager

DailyLife is a simple personal life management web app that helps you organize your daily activities and important information in one place.

## 🌐 Live Website

https://dailylife-five.vercel.app/

## ✨ Features

- ✅ Task Management
- 📅 Daily Planner
- 💰 Expense & Income Tracking
- 🛒 Shopping List
- 🔔 Reminders
- 🔗 Save Important Links
- 📝 Notes
- 💬 Save Quotes
- 💳 Bills & Subscriptions
- 📄 Documents
- 👤 Profile & Settings
- 🌙 Light & Dark Mode
- 📱 Mobile Responsive
- 📲 PWA Support
- 📊 Export Finance Reports

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage
- Service Worker
- PWA

## 💾 Data Storage

The application uses browser **LocalStorage** to save user data.

No backend or database is required.
